About SecureScan

Network reconnaissance and security analysis platform.

SecureScan

A web-based network port scanning and security assessment application.

◈

SecureScan provides a simple interface for performing authorized network reconnaissance using the Nmap scanning engine.

The application analyzes discovered open ports, identifies available services and provides a basic security risk assessment.
